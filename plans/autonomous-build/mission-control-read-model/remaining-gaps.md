# Mission Control Read Model — Remaining Gaps

- The panel is an observability projection, not an autonomous decision
  executor. Strategy and learning remain advisory and cannot create authority.
- The canonical service is an older deployed source revision; this local UI
  slice is not claimed as live deployment evidence.
- Real browser visual behavior was not exercised in this read-only release.
- Publication counts and metrics remain whatever the persisted runtime proves;
  the UI does not infer publication from `COMMAND_COMPLETED` or missing data.
- Full Mission Control coverage still needs future read-only projections for
  product artifacts, discovery opportunities, account health detail,
  publication timelines and verified external outcomes.
