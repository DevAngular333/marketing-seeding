# Remaining gaps

- Learning remains explanatory and advisory; it does not change action
  selection or create execution authority.
- Post attribution is bounded evidence for explanation only. It does not rank
  or reroute candidates and does not authorize action.
- Fingerprints are diagnostic references, not account selection or identity
  authorization.
- Metrics, publication verification and live LinkedIn evidence remain absent
  from the current canonical runtime.
- Historical UNKNOWN submissions remain quarantined and immutable.
- ORCA transport remains locally fixture-certified but unproven for a live
  irreversible submit in the current shell.
