# Remaining Gaps

1. **Live LinkedIn proof remains blocked.** There is no fresh exact live
   campaign authorization, harmless live content/session input, one-time
   window, execution grant or lease available in this shell, and ORCA is not
   available.
2. **The read model is not live publication proof.** It reports existing
   evidence; it does not create activation, acceptance or independent
   verification evidence.
3. **The UI does not yet render this new projection.** The existing dashboard
   API and `/health` expose it; a later UI slice can render read-only phase,
   latest action, blocker, UNKNOWN and verified permalink fields without adding
   controls.
4. **Legacy uncertainties without execution IDs are shown only as hashed post
   references.** This is intentional redaction and does not infer an execution.
5. **Real provider metrics, account recovery, multi-account selection and
   unattended live operation remain unverified.**
